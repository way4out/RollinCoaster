# RollinCoaster Public Deployment Guide

## GitHub Pages Activation (Immediate)

1. Go to: https://github.com/way4out/RollinCoaster/settings/pages
2. Under "Source", select: **Deploy from a branch**
3. Select branch: **main**
4. Select folder: **/ (root)**
5. Click **Save**

GitHub will auto-build and deploy from main branch.

**Live URL**: `https://way4out.github.io/RollinCoaster`

---

## Add Production Secret

1. Go to: https://github.com/way4out/RollinCoaster/settings/secrets/actions
2. Click **New repository secret**
3. Name: `VITE_PARK_TREASURY`
4. Value: `0x13653b6b8bd4b274da565faf6fa894e3418a6d10`
5. Click **Add secret**

---

## Verify Deployment

After ~2 minutes:
- Check https://github.com/way4out/RollinCoaster/actions
- Green checkmark = deployment succeeded
- Live site: https://way4out.github.io/RollinCoaster

---

## Custom Domain (Optional)

1. Point domain DNS to GitHub Pages
2. Go to repo Settings > Pages
3. Enter custom domain
4. Create CNAME file or configure DNS
